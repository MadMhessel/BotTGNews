
# Бот визуализации новостей на основе Gemini 3 Pro

## Что делает

- Принимает текст новости или поста в Telegram.
- Анализирует текст с помощью `gemini-3-pro-preview`.
- Выбирает тип визуализации (фотореализм / иллюстрация, строгость, использование текста, персонажей и т.д.).
- Формирует промт и генерирует изображение через `gemini-3-pro-image-preview`.
- Накладывает логотип (`logo.png` в корне проекта) в наименее загруженный угол.
- При необходимости добавляет заголовок на изображение.
- Возвращает 1–2 готовых изображения для поста.

## Структура

- `main.py` — точка входа, Telegram-бот (aiogram).
- `pipeline.py` — конвейер обработки: анализ → стратегия → spec → промт → генерация → постобработка.
- `analysis.py` — аналитика текста и генерация заголовка (Gemini 3 Pro).
- `strategy.py` — правила выбора типа визуала.
- `visual_spec.py` — сборка технического задания на изображение (visual_spec).
- `image_generation.py` — формирование промта и вызов `gemini-3-pro-image-preview`.
- `postprocess.py` — наложение логотипа и текста, экспорт в JPEG.
- `gemini_client.py` — создание клиента Gemini.
- `requirements.txt` — зависимости Python.
- `.env.example` — пример файла окружения.
- `run_bot.bat` — запуск бота под Windows.

## Подготовка

1. Установите Python 3.10+.
2. Создайте и активируйте виртуальное окружение (по желанию).
3. Установите зависимости:

   pip install -r requirements.txt

4. Скопируйте `.env.example` в `.env` и заполните:

   - `TELEGRAM_BOT_TOKEN` — токен бота из BotFather.
   - `GEMINI_API_KEY` — API-ключ Gemini.

5. Поместите файл `logo.png` в корень проекта.

## Запуск

- Через командную строку:

  python main.py

- Через Windows двоичный клик:

  run_bot.bat

## Примечания

- Код использует SDK `google-genai` и может потребовать корректировки параметров конфигурации
  под актуальную версию библиотеки.
- Логика анализа и стратегии вынесена в отдельные модули и может донастраиваться под конкретный канал
  и стилистику визуалов.


ВАЖНО: используется синтаксис aiogram 2.x, убедитесь, что установлена версия aiogram==2.25.1.
